# Tests that need something this repository or this host may not have.
#
# One section per resource, one test per line, in the JUnit form
# CLASSNAME::NAME that tools/ci/check_failures.py prints. A line without
# a bracketed parameter covers every parametrization of that test.
#
# The root conftest.py reads this file. For each listed test whose resource
# is absent it adds @pytest.mark.requires_resource(<resource>) and a skip
# whose reason names the resource and why it is absent. A listed test whose
# resource is present runs exactly as before; nothing here relaxes a test.
#
#   evidence_archive           parity/meep_gpu/results/ holds the records of
#                              the certification campaigns and carries their
#                              marker, EVIDENCE_ARCHIVE.json. Not part of this
#                              repository; these tests read one of its records.
#                              Without the marker the directory is a working
#                              output directory (gate runs write there).
#   torch                      PyTorch is installed.
#   meep                       MEEP (conda-forge pymeep or a source build) is
#                              installed.
#   mps_device                 PyTorch is installed and reports a usable Apple GPU
#                              (MPS).
#   single_precision_meep      MEEP is a single-precision build
#                              (mp.is_single_precision() is True): the test
#                              compares with MEEP at single-precision bounds, or
#                              asserts that MEEP returns float32 arrays.
#   certified_metal_toolchain  PyTorch and the Metal frontend of this Mac are a
#                              certified pair: the test asserts that the Metal
#                              kernels dispatch, which an uncertified pair
#                              refuses by design.
#
# How each list was derived: the evidence_archive tests fail without the
# archive and pass with it (one run of each list on the development tree,
# which holds the archive); torch, meep and single_precision_meep from runs in
# environments without PyTorch, without MEEP (the package suite and the
# harness suite), and with a double-precision MEEP;
# certified_metal_toolchain from one run under PyTorch 2.14.0, which is not
# certified; mps_device from a run without PyTorch, for a test whose own skip
# did not declare its resource.
