# meep-gpu certification reference, Apple silicon (osx-arm64): the PyPI part.
# The PyPI packages of the environment the Metal kernels were certified in, each at the
# version that environment holds and pinned to one wheel by SHA-256. networkx, setuptools
# and packaging come from the conda part (meep-gpu-ref-osx-arm64.conda.txt).
# torch: the build-tag-2 wheel, torch-2.10.0-2-cp312-none-macosx_11_0_arm64.whl, which is
# the one the certified environment installed. PyPI also carries an earlier untagged
# 2.10.0 wheel for this platform; its hash is not listed, so pip refuses it.
# autograd: added 2026-10-05 at 1.8.0, the version the certified environment holds (its
# installed files are the 1.8.0 wheel's, 39 of 39). MEEP's adjoint module (meep.adjoint)
# and MEEP's adjoint tests import it, so without it those tests fail on import and a
# corpus lift loses their rows. It requires only numpy<3 and does not take part in the
# field updates, so numerics-relevant.json does not judge it.
# shapely and nlopt: added 2026-10-11, corpus-only (numerics-relevant.json, corpus_only).
# The MEEP identity corpus (Table 2) needs them and no field update reads them:
# ex.waveguide_crossing imports nlopt, and the PyMieScatt stand-in, which
# ex.mie_scattering and ex.differential_cross_section import, imports shapely. Without
# them those rows are refused by name. Each is the cp312 macosx_11_0_arm64 wheel by
# SHA-256 (the pins the corpus legs of 2026-10-10 measured with); nlopt 2.11.0 requires
# numpy>=2,<3. The stand-in itself is not on PyPI: build script step 7 builds and installs
# it with parity/meep_gpu/rounds/1.0/build_pymiescatt_standin.py, after this file.
# llvmlite and imageio-ffmpeg: added by additions.json (the pins after the marker below).
# llvmlite 0.47.0, the cp312 macosx_11_0_arm64 wheel, is LLVM's own parser, which the test
# suite hands Triton-shaped IR to; imageio-ffmpeg 0.6.0 carries the ffmpeg executable the
# build scripts link into <prefix>/bin for the one corpus row that needs `which ffmpeg`,
# and no shared library of its own.
# Install into the prefix made from the conda part (build script step 7):
#   <prefix>/bin/python -s -m pip install --no-deps -r meep-gpu-ref-osx-arm64.pip.txt
#   <prefix>/bin/python -s <checkout>/parity/meep_gpu/rounds/1.0/build_pymiescatt_standin.py \
#       --python <prefix>/bin/python --install
#   <prefix>/bin/python -s -m pip check
#   <prefix>/bin/python -s <checkout>/tools/compare_reference_environment.py --prefix <prefix> \
#       --require-pip-lock
